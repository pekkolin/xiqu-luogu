# 戏曲锣鼓 · 电子打击垫

纯前端网页版戏曲电子锣鼓打击垫，打开浏览器即可使用，支持**手机 / iPad 多点触控**与**电脑键盘直接演奏**。

## 主要功能

- **18 种传统戏曲打击乐音色**（Web Audio API 物理建模合成，零外部音频依赖、低延迟复音）：
  - 锣类：大锣、闷大锣、小锣（上行滑音「台」）、风锣、铛子
  - 钹类：铙钹、闷钹、小钹、广钹
  - 鼓类：板鼓（单皮）、鼓边（撕边）、大堂鼓、小堂鼓
  - 板/击节：檀板、梆子、木鱼、碰铃、引磬
- **空间混响与止音**：内置「干声 / 排练 / 戏台」三档混响，支持空格键 (`Space`) 全局止音与单键「按下时止音」。
- **高度自定义编辑**：
  - 自定义打击垫行列数（2×2 至 6×6）与位置互换
  - 自定义按键主字、副标题、10 种戏曲传统配色、电脑键盘快捷键（兼容中文输入法）
  - 单键最多同时绑定 **3 种乐器**，可分别调节力度、音高与延迟（ms）
- **多方案管理**：内置「京剧武场 · 锣鼓经 (4×4)」「传统武场 · 单乐器全集 (3×4)」「精简大键 · 手机推荐 (3×3)」3 套预设，支持新建方案、自动保存及 JSON 导入导出。
- **手机端友好**：支持浏览器「添加到主屏幕」全屏打开。

> 提示：在 iPhone 上使用时，请关闭机身侧面的静音开关以确保 Web Audio 正常发声。
